Privacy Policy — TWGR Personal Incoming GR107

Last updated: October 26, 2026 · Extension version: 1.0.5

TWGR Personal Incoming GR107 helps authorized users collect incoming-attack information from an active Tribal Wars GR107 game session and deliver reports to a user-configured collector for display in designated Discord channels. The extension is intended only for game accounts the user is authorized to access.

1. Data accessed and processed

To perform its reporting function, the extension processes the configured account label, game account name and game account ID, Discord server ID, selected collector address, timestamps, and incoming-attack information visible in the game. Attack information can include village names and coordinates, names of other game players, source and target village details, command identifiers or descriptions, recognition information, and arrival times.

The extension also stores an administrator-provided authorization secret and settings in Chrome's local extension storage. The secret is used to produce HMAC authentication signatures and is not intentionally sent to the collector as a plaintext secret.

2. How the data is collected and used

When the user enables the extension, a scheduled scan attempts to read the incoming-attack pages of an open, authenticated GR107 browser tab approximately every 20 minutes. The user may also initiate a scan manually or pause scanning. Data is used only to provide per-account attack reports, identify newly observed incoming attacks, and show reporting history and status.

The extension does not intentionally collect or transmit account passwords, session cookies, general browsing history, health information, or financial information. It uses the existing authenticated game session to request the necessary GR107 pages.

3. Transmission and sharing

Scan results are transmitted to the collector endpoint explicitly configured by the user or administrator. The collector processes and stores reports, then publishes or updates reports in administrator-designated Discord channels. Report visibility depends on that Discord server's channel permissions. The collector's hosting provider and Discord may process data as needed to operate these services.

Collector connections require HTTPS except when the user deliberately configures a local endpoint at localhost or 127.0.0.1. Requests to the collector are authenticated with signed headers.

Data is not sold, shared for advertising, used for personalized advertising, or used to assess creditworthiness.

4. Storage and retention

Configuration, scan status, and the authorization secret are kept in Chrome local extension storage. The collector stores current incoming records and historical scan information in its database, and Discord stores the reports posted to its channels. No fixed automatic deletion period is represented here: server-side records and Discord messages may remain until the administrator deletes them. A user who wants collector-side or Discord records removed should contact the system administrator.

5. Security and user controls

Users can pause the extension and remove it to stop future scans. Deleting the extension does not itself delete reports already stored in the collector or Discord. Protect the collector authorization secret and configure Discord channel permissions to limit access to reports. No system can guarantee absolute security.

6. Limited Use

Use of information obtained through Chrome APIs follows the Chrome Web Store User Data Policy, including its Limited Use requirements. The extension uses the data only to provide its disclosed reporting function and related security and reliability operations. It does not use this information to deliver advertisements, and human access to stored reports is limited to authorized administration and support, security, or legally required purposes as applicable.
